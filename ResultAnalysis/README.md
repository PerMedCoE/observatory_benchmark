# Observatory Benchmark Analysis Notebooks

This directory contains the analysis notebooks used to compare BioDynaMo, Chaste, CompuTiX, PhysiCell, and TiSim on diffusion, cell-cycle, mechanics, and monolayer-growth benchmarks. The notebooks load simulator-specific exports, convert them into common physical units, compare them with analytical or experimental references, and generate figures and tabular summaries for the manuscript and supplementary material.

The notebooks are intended to be run from the repository root. Most paths are defined relative to `/home/tntiniak/Work/observatory_benchmark` (or are discovered from the current working directory). Input files are not regenerated by these notebooks unless explicitly noted; preprocessing notebooks in the analysis subdirectories provide the required exports for some PhysiCell results.

## Publication workflow

For a reproducible paper analysis:

1. Ensure the simulator result directories and analytical/reference files exist at the paths defined in each notebook.
2. Run the notebooks in the order required by the corresponding benchmark. In particular, use the PhysiCell export notebooks before running comparisons that require exported concentration or mechanics tables.
3. Inspect the validation cells and printed coverage checks before using a figure or metric in the manuscript.
4. Use the high-resolution PNG/SVG files written to `ResultAnalysis/plots/` for manuscript figures and the files written to `SuppMat/SuppMatPlots/` for supplementary figures.

The notebooks preserve simulator-native observations whenever possible. They do not silently smooth, resample, or interpolate simulator curves except where a notebook explicitly documents interpolation for a reference or diagnostic comparison.

## Diffusion decay

[`diffusion_decay_tools_comparison.ipynb`](./diffusion_decay_tools_comparison.ipynb) compares whole-box average and center concentrations for five tools against `ResultAnalysis/analytical_solutions/diffusion/Decay/analytical_values.csv`.

### Inputs and harmonization

- BioDynaMo, Chaste, CompuTiX, PhysiCell, and TiSim outputs are loaded through tool-specific readers into a common long-form table.
- CompuTiX uses the four `dt-s-0-006_N-*.yaml` runs with `N = 7, 15, 31, 63`; the 0.0006-second runs are excluded.
- Times are expressed in minutes and concentrations in µM. CompuTiX seconds are converted to minutes and mol/m³ values to µM. PhysiCell exported concentrations are used after their particles/µm³-to-µM conversion.
- Both average concentration and center concentration are retained. The center definition is the value supplied by each tool/export; for PhysiCell it is based on the central voxels.

### Comparison and selection

Each native simulator timestamp is matched to the nearest analytical CSV timestamp within `0.0005 min`. The loaded timestamps are not changed, and no interpolation is used for the primary comparison. Unmatched samples raise an error rather than being silently discarded. Absolute error, relative error, time-weighted summaries, L2 error, maxima, sample counts, and time spans are calculated.

One run per tool is selected using the lowest whole-box-average mean absolute error (MAE), with documented tie-breakers based on relative error, resolution, time step, and run ID. Those same selected runs are then used for the average and center concentration plots.

### Outputs

The notebook writes pointwise and run-level metrics, including `pointwise_errors.csv`, `run_error_metrics.csv`, and `best_run_error_metrics.csv`, together with absolute-error, relative-error, full-time, and Nature-style concentration/error figures. Supplementary outputs are placed under `SuppMat/SuppMatPlots/diffusion_decay_comparison`; manuscript-oriented outputs are placed under `ResultAnalysis/plots/diffusion_decay`.

## Diffusion uptake by cells

[`diffusion_uptake_tools_comparison.ipynb`](./diffusion_uptake_tools_comparison.ipynb) evaluates the uptake-by-cells benchmark using the same two concentration observables: whole-box average and center concentration.

### Inputs and harmonization

The notebook reads the five simulator result families and the analytical uptake reference at `ResultAnalysis/analytical_solutions/diffusion/Cellsatcenter/analytical_values.csv`. BioDynaMo timestamps are converted from seconds to minutes without rounding; the other loaders preserve their native time values. Concentration and resolution metadata are standardized into a common table.

### Comparison and selection

The primary comparison uses exact equality on the rounded analytical time grid. It does not use nearest-neighbor matching, interpolation, or silent duplicate removal. Duplicate matches generated by the rounded grid are explicitly aggregated and reported where required by the notebook’s validation workflow. Relative and absolute errors are computed for every run.

The best run is selected separately for each tool and concentration metric using mean relative error, then selected again using mean absolute error. The notebook reports the coverage of the exact-time comparison and also provides an explicitly labelled interpolated-reference diagnostic section; the interpolated comparison is not a replacement for the primary exact-time result.

### Outputs

Outputs include concentration time courses, relative-error curves, absolute-error curves, exact-match coverage summaries, interpolated-reference diagnostics, and Nature-style concentration/error figures. Supplementary results are written to `SuppMat/SuppMatPlots/diffusion_uptake_comparison`; manuscript-oriented results are written to `ResultAnalysis/plots/diffusion_uptake`.

## Fixed cell-cycle volume comparison

[`fixed_cell_cycle_comparison.ipynb`](./fixed_cell_cycle_comparison.ipynb) compares the volume dynamics of BioDynaMo, Chaste, CompuTiX, PhysiCell, and TiSim over a repeated fixed cell cycle, alongside experimental reference points.

### Processing

- Chaste records multiple 11-field cell records per timestep; the notebook extracts and aggregates the relevant cell-volume values.
- TiSim cell-volume columns are averaged at each time point.
- PhysiCell timestamps are converted from minutes to hours.
- Absolute simulator volumes are normalized by the mean volume at the first time point and reported as a percentage of initial volume. Experimental values are already represented as relative percentages.
- Time and normalized volume values are assembled into one validated long-form comparison table. The notebook checks that all expected tools are present, values are finite, and each series is ordered in time.

The plot shows the normalized volume trajectories and experimental reference points, with the three repeated 18-hour phase blocks annotated by vertical boundaries.

### Outputs

The publication figure is saved as [`fixed_cell_cycle_volumes.png`](./plots/cell_cycle_plots/fixed_cell_cycle_volumes.png) and [`fixed_cell_cycle_volumes.svg`](./plots/cell_cycle_plots/fixed_cell_cycle_volumes.svg) under `ResultAnalysis/plots/cell_cycle_plots`.

## External impulse mechanics comparison

[`mechanics_external_impulse_comparison.ipynb`](./mechanics_external_impulse_comparison.ipynb) compares x-position and x-velocity responses from the mechanics tools with the analytical external-impulse solution.

### Processing

The notebook reads the tool-specific position, velocity, YAML, and CSV exports, extracts the x component, and converts all traces to seconds, µm, and µm/s. Stable colors and line styles are applied across figures. The analytical position and velocity traces are loaded from `ResultAnalysis/analytical_solutions/mechanics/analytical_values.csv`.

Velocity error is evaluated at analytical reference times within each tool’s simulated interval. The notebook interpolates each tool’s velocity trace only for this common-reference-time error calculation; the plotted simulator traces retain their recorded samples.

### Figures

The notebook produces individual position and velocity figures, combined position/velocity figures, a velocity-plus-mean-error figure, and a common-overlap velocity-error figure. The position and velocity plots are now generated as separate figures rather than being forced into one two-panel output.

Outputs are written to `SuppMat/SuppMatPlots/mechanics_external_impulse` and focused figures are also written to `ResultAnalysis/plots/mechanics_external_impulse`.

## Extended-Hertz mechanics comparison

[`mechanics_pushing_extended_hertz.ipynb`](./mechanics_pushing_extended_hertz.ipynb) analyzes the relaxation of two interacting cells under the extended-Hertz force law for drag values `0.01`, `0.1`, and `1`.

### Model and inputs

The notebook defines the composite Young modulus, adhesion energy density, cell radii, initial overlap, equilibrium overlap, and the extended-Hertz force. It integrates the overdamped equation of motion with `scipy.integrate.solve_ivp` and compares the analytical trajectory with BioDynaMo, Chaste, CompuTiX, PhysiCell, and TiSim outputs. Tool-specific loaders convert all time values to seconds and all overlap values to a common scale.

### Figures and metrics

The notebook contains all-drag comparison figures, drag-specific views, final-overlap error calculations, and error tables. The focused final plot uses `drag = 1` only, shows the complete available time series without a `T_MAX` truncation, and has no inset zoom. The all-drag sections remain available for comparing the effect of drag across tools.

Outputs are written to `SuppMat/SuppMatPlots/mechanics_pushing_extended_hertz` and `ResultAnalysis/plots/mechanics_pushing_extended_hertz`.

## Monolayer growth comparison

[`monolayer_comparison.ipynb`](./monolayer_comparison.ipynb) reproduces the colony-diameter comparison across the five tools and experimental observations.

### Inputs and processing

The experimental and BioDynaMo series are defined directly in the notebook because no corresponding on-disk result files are available for this benchmark. Chaste, CompuTiX, PhysiCell, and TiSim are loaded from their repository exports. All series are standardized to time in days and colony diameter in µm. PhysiCell and CompuTiX are restricted to the observation window beginning at day 14.

The experimental diameter is linearly interpolated to estimate the reference diameter at simulator times. The figure’s first panel shows the diameter trajectories; the second shows each simulator’s deviation from the interpolated experimental curve.

### Outputs

The combined publication figure is saved as [`monolayer_comparison_combined.png`](./plots/monolayer_plots/monolayer_comparison_combined.png) and [`monolayer_comparison_combined.svg`](./plots/monolayer_plots/monolayer_comparison_combined.svg) under `ResultAnalysis/plots/monolayer_plots`.

## Units and interpretation notes

- Diffusion concentrations are reported in µM; diffusion time is reported in minutes.
- Cell-cycle time is reported in hours and volume is normalized to the first-time-point volume or reported experimental percentage.
- Mechanics time is reported in seconds, position/overlap in µm, and velocity in µm/s.
- Monolayer time is reported in days and diameter in µm.
- “Best run” means best according to the metric and selection rule stated by that notebook; it is not necessarily the highest spatial or temporal resolution.
- Analytical and experimental references are comparison baselines, not additional simulator runs.

## Reproducibility and reporting checklist

Before publication, record the repository revision, input-data revision, Python environment, notebook execution order, and the exact output files used in each manuscript panel. Confirm that all expected input files are present, that validation cells pass, and that any interpolated diagnostic is clearly distinguished from the primary native-time comparison.
